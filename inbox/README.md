# Inbox

The only place for things that don't have a home yet: quick captures, half-ideas, a Word file the
DM just edited, a screenshot, a bug list jotted mid-session.

**It is triaged to empty at every session wrap.** Each item is either filed into its home
(`CLAUDE.md` → "Where things go"), folded into an existing doc, or deleted. `npm run check` reports
how many items are waiting. This README is the only permanent resident.
