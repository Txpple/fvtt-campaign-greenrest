# Sessions

The record of play: one directory per game session, generated by the **session-scribe** skill
(`fvtt-mcp-sessionscribe`, the `scribe` MCP) from the Craig recording and the Foundry chat log. House
style is `STYLE.md`.

```
sessions/YYYY-MM-DD/
  craig-info.json           recording metadata (sanitized — no download key, no Discord identities)
  transcript-segments.json  raw per-track whisper output
  chatlog.json              Foundry chat export (rolls, whispers) for the recording window
  transcript.md             the merged timeline: speech + 🎲 rolls + 💬 chat + 🤫 whispers
  transcript.html / .pdf    the same, printed — every session
  transcript-public.md      the same, minus every whisper and blind roll: what the table saw
  recap.md                  canonical session record (GM voice, spoiler-tolerant)
  recap.html / .pdf         1 · player-safe recap — the only player-facing artifact
  recap-print.html          the block-layout print twin the PDF is rendered from
  combat-stats.md
  combat-log.html / .pdf    2 · combat report (GM-facing, exact numbers)
  gm-notes-story.md / .html / .pdf      3 · GM notes — plot: canon, promises, open threads, quotes
  gm-notes-mechanics.md / .html / .pdf  4 · GM notes — bookkeeping, automation, rulings, table
  img/                      the recap's illustrations, numbered in reading order
```

Not every session has every file; the set grew over the campaign:

- **Sessions 1–5** — transcript, `recap.md` + `recap.html`, and a single `gm-notes.md`. Their
  `recap.pdf` (from `recap.md`, so spoiler-tolerant) and `gm-notes.html` / `.pdf` were rendered for
  this public copy by `scripts/render-session-docs.mjs`, in the scribe's style.
- **Session 6** — adds the combat report and the recap PDF; its GM notes PDF was rendered the same
  way.
- **Sessions 7–9** — the four-document set, each as HTML + PDF (`gm-notes.md` split into story and
  mechanics).
- **Sessions 8–9** — illustrated recaps (`img/`, `recap-print.html`).
- **Session 9** — `transcript-public.md`.
- **Every session** — `transcript.html` / `.pdf`, rendered for this public copy (the scribe never
  printed transcripts).

**Spoiler boundary:** `recap.html` and the Session Diary page are written only from what the players
saw at the table. Whispers, blind rolls and GM-only material may inform `recap.md` and the GM notes,
never `recap.html`.

**The transcripts are verbatim.** Machine transcription of five voice tracks, merged on the clock:
mis-hearings, cross-talk and the table's out-of-game chatter are all in there. Speakers are the
characters (or "DM"); the players appear by first name only.

Audio was never committed (size); the transcript is the durable artifact.
